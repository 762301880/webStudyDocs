



## 娱乐扩展

### canvas-confetti 烟花特效

> 例如我们想要提交某个按钮庆祝一下,满屏幕的烟花特效多好看啊

1、在线演示官网（可在线调试所有烟花参数、预览效果）

[https://www.kirilv.com/canvas-confetti/](https://link.wtturl.cn/?target=https%3A%2F%2Fwww.kirilv.com%2Fcanvas-confetti%2F&scene=im&aid=497858&lang=zh)

2、GitHub 源码仓库（完整文档、API 参数、示例代码）

[https://github.com/catdad/canvas-confetti](https://link.wtturl.cn/?target=https%3A%2F%2Fgithub.com%2Fcatdad%2Fcanvas-confetti&scene=im&aid=497858&lang=zh)

3、NPM 官方包页面

[https://www.npmjs.com/package/canvas-confetti](https://link.wtturl.cn/?target=https%3A%2F%2Fwww.npmjs.com%2Fpackage%2Fcanvas-confetti&scene=im&aid=497858&lang=zh)

4、CDN 在线引入地址（无需 npm 安装，直接网页引入使用）

最新稳定版：

```html
<script src="https://cdn.jsdelivr.net/npm/canvas-confetti@1.9.4/dist/confetti.browser.min.js"></script>
```

网站可以在线调试内容

- 粒子数量、扩散范围、发射角度
- 自定义彩带颜色、形状（方形、圆形、星星）
- 发射位置、重力、下落速度
- 预设礼花、持续飘落、左右连发、烟花升空等全套场景模板
