## Element Plus 三级路由 / 侧边栏目录  方案

> 适用：后台管理系统（Vue3 + Vite + VueRouter4 + Element Plus） 大厂规范要点：
>
> 1. **路由配置扁平化，不嵌套多层 RouterView**（避免多层`<router-view>`坑）
> 2. 通过 `meta` 配置层级、菜单标题、图标、排序、是否隐藏
> 3. 一级目录 / 二级目录 只做分组，**只有最末三级才绑定组件**
> 4. 侧边栏自动根据路由生成菜单，支持折叠、面包屑、权限控制
> 5. 路由地址规范：`/一级/二级/三级`，统一小写横线命名

## 目录结构

```html
src/
├── views/
│   ├── system/            # 一级：系统管理
│   │   ├── user/          # 二级：用户管理
│   │   │   ├── list.vue   # 三级：用户列表
│   │   │   ├── detail.vue # 三级：用户详情
│   │   ├── role/          # 二级：角色管理
│   │   │   ├── list.vue
│   ├── monitor/           # 一级：监控中心
│   │   ├── server/        # 二级：服务器监控
│   │   │   ├── info.vue   # 三级
├── router/
│   ├── index.js           # 路由入口
│   └── modules/           # 大厂拆分：按业务模块拆分路由（重点！）
│       ├── system.js
│       ├── monitor.js
├── layout/
│   └── index.vue          # 主布局（包含 el-menu 侧边栏）
```

## 核心路由设计

> ❌ 不推荐：路由嵌套三级 `<router-view>`（层级太深，缓存、面包屑很难处理） 
>
> ✅ 大厂通用：**路由都是一级路由，使用 meta.parent 构造菜单层级**

### router/index.js

```js
import { createRouter, createWebHistory } from 'vue-router'
import Layout from '@/layout/index.vue'

// 引入模块路由
import systemRoutes from './modules/system'
import monitorRoutes from './modules/monitor'

export const constantRoutes = [
  {
    path: '/login',
    component: () => import('@/views/login/index.vue'),
    meta: { hidden: true }
  },
  {
    path: '/',
    component: Layout,
    redirect: '/dashboard',
    children: [
      {
        path: 'dashboard',
        name: 'Dashboard',
        component: () => import('@/views/dashboard/index.vue'),
        meta: { title: '首页', icon: 'House' }
      }
    ]
  }
]

// 动态业务路由（三级菜单全部放在这里）
export const asyncRoutes = [
  ...systemRoutes,
  ...monitorRoutes
]

const router = createRouter({
  history: createWebHistory(),
  routes: [...constantRoutes, ...asyncRoutes]
})

export default router

```

### router/modules/system.js（三级菜单示例，重点模板）

```js
/**
 * 一级菜单：系统管理 path:/system
 * 二级菜单：用户管理 /system/user
 * 三级菜单：用户列表 /system/user/list
 */
export default [
  {
    path: '/system',
    component: Layout,
    redirect: '/system/user/list',
    // 【一级菜单】分组节点，不渲染页面，仅用于侧边栏父节点
    meta: {
      title: '系统管理',
      icon: 'Setting',
      // 标记这是一级父菜单
      level: 1
    },
    children: [
      {
        path: '/system/user',
        redirect: '/system/user/list',
        // 【二级菜单】分组节点
        meta: {
          title: '用户管理',
          level: 2,
          parentPath: '/system' // 绑定父级path，用于菜单树构建
        },
        children: [
          // ========== 三级路由（真实页面）==========
          {
            path: '/system/user/list',
            name: 'SystemUserList',
            component: () => import('@/views/system/user/list.vue'),
            meta: {
              title: '用户列表',
              level: 3,
              parentPath: '/system/user',
              // 权限标识，用于按钮级权限控制
              permission: ['system:user:list']
            }
          },
          {
            path: '/system/user/detail',
            name: 'SystemUserDetail',
            component: () => import('@/views/system/user/detail.vue'),
            meta: {
              title: '用户详情',
              level: 3,
              parentPath: '/system/user',
              hidden: true // 不在侧边栏显示（弹窗/详情页常用）
            }
          }
        ]
      },
      {
        path: '/system/role',
        redirect: '/system/role/list',
        meta: {
          title: '角色管理',
          level: 2,
          parentPath: '/system'
        },
        children: [
          {
            path: '/system/role/list',
            name: 'SystemRoleList',
            component: () => import('@/views/system/role/list.vue'),
            meta: {
              title: '角色列表',
              level: 3,
              parentPath: '/system/role'
            }
          }
        ]
      }
    ]
  }
]

```

## Layout 侧边栏 el-menu 渲染逻辑（大厂通用递归菜单）

### layout/index.vue

```vue
<template>
  <el-container style="height: 100vh;">
    <el-aside width="220px">
      <el-menu
        :default-active="$route.path"
        router
        collapse-transition
      >
        <!-- 递归组件渲染多级菜单 -->
        <MenuTree :routes="menuList" />
      </el-menu>
    </el-aside>
    <el-main>
      <router-view />
    </el-main>
  </el-container>
</template>

<script setup>
import { computed } from 'vue'
import { useRoute } from 'vue-router'
import MenuTree from './components/MenuTree.vue'

const route = useRoute()

// 过滤出需要展示的菜单
const menuList = computed(() => {
  return filterRoutes(route.matched)
})

function filterRoutes(routes) {
  return routes.filter(item => !item.meta?.hidden)
}
</script>

```

## 优势（为什么都这么写）

1. **路由地址完整可读** `/system/user/list`，方便埋点、权限拦截、日志
2. **仅叶子节点加载页面**，父级只做分组，不会出现空白页面
3. 菜单组件递归通用，三级、四级、五级菜单无需改代码
4. 方便后端动态路由：后端返回树形菜单结构，和前端结构一一对应
5. 配合 `meta.permission` 轻松实现 RBAC 权限管控
6. `hidden:true` 控制详情页、弹窗页面不在侧边栏展示

## 访问路径预览

```bash
一级：系统管理（父目录，不可点击）
├─二级：用户管理（父目录，不可点击）
│  └─三级：用户列表 → /system/user/list
│  └─三级：用户详情 → /system/user/detail（侧边隐藏）
├─二级：角色管理
│  └─三级：角色列表 → /system/role/list
```

## 可选扩展规范（大厂统一约束）

1. `name` 路由命名：大驼峰 `SystemUserList`，全局唯一
2. path 全部小写，多单词横线 `user-log`
3. meta 统一字段：
   - title：菜单名称
   - icon：Element Plus 图标名称
   - hidden：是否侧边隐藏
   - permission：权限字符串
   - sort：排序号
4. 路由懒加载统一写法 `() => import()`
