## Vue 文件夹组件的组织与命名规范

在 Vue 项目中，合理的文件夹和组件组织结构对于代码的可维护性和团队协作至关重要。以下是 Vue 项目中文件夹组件的常见组织方式及命名规范。

## 文件夹结构与用途

1. **assets** 文件夹 存放静态资源（如图片、字体等），通常使用 `kebab‑case` 命名，例如：`logo.png` 或 `icon‑fonts/`。
2. **components** 文件夹 存放可复用的 Vue 组件，建议使用 `PascalCase` 命名，例如：`BaseButton.vue` 或 `UserCard.vue`。
3. **views** 文件夹 存放页面级组件（通常与路由对应），建议使用 `kebab‑case` 命名，与路由路径保持一致，例如：`user‑profile.vue` 或 `order‑list.vue`。
4. **router** 文件夹 存放路由配置文件，建议使用 `kebab‑case` 命名，例如：`index.js` 或 `user‑routes.js`。
5. **stores** 文件夹 存放状态管理模块（如 Pinia 或 Vuex），建议使用 `PascalCase` 命名，例如：`UserStore.ts` 或 `CartStore.ts`。
6. **utils** 文件夹 存放工具函数库，建议使用 `camelCase` 命名，例如：`dateFormat.ts` 或 `apiHelpers.js`。
7. **services** 文件夹 存放 API 服务层，建议使用 `PascalCase` 命名，例如：`UserService.ts` 或 `ProductService.ts`。

## 组件命名规范

1. 组件文件使用 `PascalCase` 命名，例如：`UserProfile.vue` 或 `BaseButton.vue`。
2. 路由组件与路由路径保持一致，使用 `kebab‑case` 命名，例如：`user‑profile.vue`。
3. 状态管理文件使用 `PascalCase` 命名，例如：`UserStore.ts`，导出名以 `use` 开头，例如：`useUserStore`。
4. 工具函数文件使用 `camelCase` 命名，例如：`dateFormat.ts`。
5. 测试文件使用 `kebab‑case` 命名，并添加 `.spec` 后缀，例如：`user‑profile.spec.js`。
